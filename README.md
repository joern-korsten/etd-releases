# Trainings-Dashboard für Windows

Ein privates Trainings-Dashboard für Radfahrer: Es liest deine Fahrten (Wahoo, Garmin) und deine Erholungswerte (Garmin), rechnet Belastung, Form und Erholung und sagt dir jeden Morgen, was heute sinnvoll ist. **Alles bleibt auf deinem eigenen PC.** Es gibt keinen Server und kein Konto bei uns.

## Herunterladen und starten

1. Rechts unter **Releases** die neueste Version öffnen und unter „Assets“ die Datei `Trainings-Dashboard-….zip` herunterladen.
2. Im Ordner „Downloads“ **Rechtsklick auf die ZIP-Datei → „Alle extrahieren …“ → „Extrahieren“**.
   Bitte nicht direkt in der ZIP-Datei doppelklicken: Dort fehlen dem Programm seine Dateien.
3. Im entpackten Ordner `Trainings-Dashboard` öffnen und **`Trainings-Dashboard.exe` doppelklicken**.
4. Der Browser zeigt, wie die Einrichtung läuft (etwa eine Minute). Danach führt dich der Einrichtungsassistent Schritt für Schritt bis zu deinem ersten Tagesbriefing.

Danach läuft das Dashboard unten rechts im **Infobereich** (Symbol mit grüner Pulslinie) und startet mit Windows. Öffnen: Doppelklick auf das Symbol oder „Trainings-Dashboard“ im Startmenü. Den entpackten Download-Ordner kannst du löschen.

## Gut zu wissen

- **Smart App Control / Virenschutz:** Die Startdatei ist das offizielle, signierte Python der Python Software Foundation. Windows lässt es ohne Warnung starten.
- **Update:** Die neue Version genauso herunterladen, entpacken und doppelklicken. Deine Daten bleiben erhalten.
- **Entfernen:** Windows-Einstellungen → Apps → Installierte Apps → Trainings-Dashboard → Deinstallieren. Du wirst gefragt, ob deine Trainingsdaten erhalten bleiben sollen.
- **Wo liegen meine Daten?** In `%LOCALAPPDATA%\Trainings-Dashboard\Daten`, oder in dem Ordner, den du im Profil gewählt hast.

Dieses Repository enthält nur die fertigen Downloads.
